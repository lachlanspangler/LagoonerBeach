# ADR 0006 — Product name: Lagooner Beach

- Status: accepted (user's choice) · Date: 2026-10-16

## Decision
The game ships as **Lagooner Beach** (home-screen short name **Lagooner**, because 14 characters
truncates on most launchers). "Atoll" was the working title.

## What changed / what didn't
- Renamed everything a player sees: page title, PWA manifest, Capacitor `appName`, iOS display
  name, Android `app_name`, menu header, share text, README/CLAUDE.md headings.
- **Kept on purpose:** localStorage keys (`atoll.v1.*`) and the daily seed salt (`atoll-daily-v1`)
  — renaming them would wipe existing progress and change every daily. Code identifiers
  (`window.__atoll`, file names) also stay; they're internal.
- Kept the in-game term "Atoll!" (the callout for a 12+ lagoon) and the "Atoll" style: an atoll is
  literally a ring around a lagoon, which is the mechanic.
- Bundle id is still the placeholder `com.example.atoll` until the owner provides a real one.

## Still needed
Store/trademark availability check for "Lagooner Beach" (owner).
