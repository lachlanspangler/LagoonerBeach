### I-001 — Hollow (loop clear) (chosen)
- **Pitch:** Close a loop of blocks and everything inside it pops.
- **Closest existing:** Block Blast + Go capture + Two Dots squares
- **What's new:** Enclosure replaces line clears; holes — the genre's core fear — become the way you score.
- **Scores (R1..R14):** 2 2 2 1 2 2 2 2 2 2 2 2 2 2 → **27**/28, gates pass (meas)
- **Value/effort:** 10/4
- **Reason:** Chosen (ADR 0001). Only candidate passing every gate on measured data; huge planning headroom; big loops form a visible jackpot.
- **Data:** hollow8-ramp2: median moves random/firstFit/greedy/search 17/27/80/488; score skill 53.7×; firstFit÷search 0.03, greedy÷search 0.12; 2.2 moves/clear; median best pocket 19 cells. R4=1: greedy sessions too long until ramp is tuned. R2 needs a scripted first tray (pocket in 2 moves).

### I-003 — Flip (XOR stamp) (prototyped)
- **Pitch:** Every block flips the tiles it lands on.

### I-004 — Exact Count (prototyped)
- **Pitch:** Each row and column clears when it holds exactly its number.
- **Closest existing:** Nonograms + Block Blast
- **What's new:** Clear condition is an exact count, not 'full'; overshooting a line kills it until a crossing line clears.
- **Scores (R1..R14):** 2 1 1 0 2 1 2 2 1 2 2 1 2 2 → **21**/28, gates FAIL (meas)
- **Value/effort:** 6/3
- **Reason:** Rejected: lines clear too easily, games never end for greedy/search; greedy ≈ search (0.90–0.94) → shallow. Numbers add reading load.
- **Data:** exact: 101/199/500/500 moves; exact-hard 35/83/500/500; greedy÷search 0.94 / 0.90.
